# Documentación

## Descripción

Esta carpeta reúne la documentación elaborada para facilitar la instalación, configuración y utilización del sistema desarrollado en este proyecto. Los manuales describen los procedimientos necesarios para preparar el entorno de ejecución, configurar los componentes del sistema y operar la aplicación de manera adecuada.

## Contenido

- **Manual de Configuración:** Documento que describe el proceso de instalación del software, configuración del entorno de desarrollo, dependencias requeridas y parámetros necesarios para la correcta ejecución del sistema.

- **Manual de Usuario:** Documento que explica el funcionamiento general de la aplicación, la arquitectura del sistema, las principales técnicas implementadas y el procedimiento para utilizar las funcionalidades desarrolladas.

## Objetivo

Proporcionar la documentación necesaria para que otros usuarios puedan instalar, configurar y utilizar el sistema de forma adecuada, favoreciendo la reproducibilidad y el mantenimiento del proyecto.
