
# Manual de Usuario

## Descripción

Esta carpeta contiene el manual de usuario del sistema desarrollado en este proyecto. El documento explica el funcionamiento de la aplicación, la organización de sus módulos y el procedimiento para utilizar las diferentes funcionalidades implementadas.

## Contenido

- Descripción general del sistema.
- Arquitectura de la aplicación.
- Técnicas implementadas.
- Procedimiento de utilización.
- Recomendaciones para la operación del sistema.

## Objetivo

Proporcionar una guía práctica para el uso del sistema, facilitando su operación y permitiendo que el usuario aproveche correctamente las funcionalidades desarrolladas durante el proyecto.
