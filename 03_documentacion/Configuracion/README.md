
# Manual de Configuración

## Descripción

Esta carpeta contiene el manual de configuración del sistema desarrollado en este proyecto. El documento describe los pasos necesarios para preparar el entorno de ejecución e instalar las herramientas y dependencias requeridas para el funcionamiento de la aplicación.

## Contenido

- Requisitos de hardware y software.
- Instalación de dependencias.
- Configuración del entorno de desarrollo.
- Configuración de la comunicación Bluetooth.

## Objetivo

Guiar al usuario en el proceso de instalación y configuración del sistema, asegurando que todos los componentes queden correctamente preparados para su ejecución.
