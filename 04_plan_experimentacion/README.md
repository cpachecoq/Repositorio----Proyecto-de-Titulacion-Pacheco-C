
# Plan de Experimentación

## Descripción

Esta carpeta reúne la documentación generada durante la planificación y ejecución del proceso de evaluación del sistema desarrollado. Incluye los instrumentos utilizados para la valoración por parte de expertos, el protocolo de aplicación, los resultados obtenidos y el material de apoyo empleado durante la demostración del proyecto.

## Contenido

- **Protocolo:** Documento que describe el procedimiento seguido durante la experimentacion, las actividades realizadas y las consideraciones establecidas para garantizar la correcta aplicación del proceso.

- **Encuesta SUS-TAM:** Instrumento de evaluación aplicado a los expertos, conformado por el cuestionario de caracterización, la escala System Usability Scale (SUS), el modelo Technology Acceptance Model (TAM) y preguntas abiertas.

- **Resultados de la Encuesta:** Archivos generados a partir de Google Forms que contienen las respuestas obtenidas durante el proceso de evaluación y que sirvieron como base para el análisis de resultados presentado en la tesis.

- **Diapositivas:** Presentación utilizada durante el desarrollo del plan de experimentación para introducir el proyecto, explicar su funcionamiento y guiar la demostración realizada a los expertos.

## Objetivo

Documentar el proceso de evaluación del sistema mediante la recopilación de los instrumentos, evidencias y resultados obtenidos durante el plan de experimentación, facilitando la comprensión y la reproducibilidad de la metodología aplicada.
