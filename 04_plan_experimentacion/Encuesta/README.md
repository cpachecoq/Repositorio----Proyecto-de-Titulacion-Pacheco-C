
# Encuesta SUS-TAM

## Descripción

Esta carpeta contiene el instrumento de evaluación aplicado a los expertos durante el plan de experimentación.

## Contenido

- Cuestionario de caracterización.
- Escala System Usability Scale (SUS).
- Modelo Technology Acceptance Model (TAM).
- Preguntas abiertas.

## Objetivo

Recopilar la percepción de los expertos sobre la usabilidad, aceptación y funcionamiento del sistema desarrollado.
