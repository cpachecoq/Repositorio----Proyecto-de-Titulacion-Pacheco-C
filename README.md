# Repositorio----Proyecto-de-Titulacion-Pacheco-C
Repositorio donde se encuentra el codigo y las evidencias del desarrollo de proyecto de titulacion con el Asistente Robotico Cavia Porcellus


## Descripción

Este repositorio contiene el código fuente y la documentación correspondiente al trabajo de titulación desarrollado en la Universidad Politécnica Salesiana. El proyecto implementa un módulo de control de movimiento basado en visión por computador y aprendizaje profundo que permite a un asistente robótico desplazarse de forma autónoma hacia pictogramas representativos de las culturas Inca y Cañari, contribuyendo al desarrollo de actividades educativas dirigidas a niños.

Además del código fuente, el repositorio incluye las evidencias experimentales, documentación técnica, material utilizado durante el proceso de evaluación y el acceso al conjunto de datos empleado para el entrenamiento de los modelos de inteligencia artificial.

## Estructura del repositorio

### Código fuente

El directorio principal contiene el código fuente de la aplicación desarrollado en Python, incluyendo los módulos responsables de la interfaz gráfica, detección de pictogramas, navegación del robot y comunicación con el sistema embebido.

### 01_notebooks_entrenamiento

Contiene los cuadernos de Jupyter utilizados durante el entrenamiento y evaluación de los modelos YOLO y LLaVA, así como las métricas obtenidas durante el proceso experimental.

### 02_videos

Incluye las evidencias audiovisuales correspondientes a las pruebas de movimiento del robot y la demostración realizada durante el plan de experimentación.

### 03_documentacion

Contiene los manuales de configuración y de usuario elaborados para la instalación, configuración y utilización del sistema.

### 04_plan_experimentacion

Reúne la documentación correspondiente al plan de experimentacion con expertos, incluyendo el protocolo n, la encuesta SUS-TAM, los resultados obtenidos y la presentación utilizada durante la demostración del proyecto.

### 05_dataset

Contiene la documentación del conjunto de datos utilizado para el entrenamiento del modelo, así como el enlace al proyecto alojado en Roboflow.
