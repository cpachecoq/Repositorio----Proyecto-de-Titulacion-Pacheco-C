# Dataset

## Descripción

Esta carpeta corresponde al conjunto de datos utilizado para el entrenamiento y validación del modelo de detección de pictogramas implementado en el proyecto.

El dataset fue construido específicamente para esta investigación mediante la recopilación de imágenes propias, el etiquetado manual utilizando Roboflow y la aplicación de técnicas de aumentación de datos para incrementar la variabilidad de las muestras empleadas durante el entrenamiento.

## Características del dataset

- Imágenes recopiladas para los pictogramas correspondientes a las culturas Inca y Cañari.
- Etiquetado manual mediante la plataforma Roboflow.
- Formato de anotaciones compatible con YOLO.
- División del conjunto de datos en entrenamiento, validación y prueba.
- Inclusión de imágenes negativas para reducir falsas detecciones.

## Contenido

En esta carpeta se documenta el conjunto de datos utilizado para el entrenamiento. Debido al tamaño del dataset (superior al límite permitido por GitHub para un único archivo), el conjunto completo se encuentra alojado en Roboflow.
